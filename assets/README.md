## WagLog

The two WagLog images are selected marketing compositions from the earlier Capacitor prototype, dated 21 August 2026. The original asset documentation identifies the displayed dog and activity history as fictional data added to the Simulator. They are not representations of the current SwiftUI interface.

- `waglog/prototype-dashboard.png` — fictional dog profile and daily activity dashboard.
- `waglog/prototype-trends.png` — fictional activity and observation trends.
